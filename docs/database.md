# Database Schema & Model Design

Shared PostgreSQL database via Prisma ORM:
- **User & Passkey**: WebAuthn credential public keys, zero password storage.
- **Project & ProjectImage**: Portfolio showcase items with responsive image ordering.
- **Experience & Education**: Career timeline and institutional milestones.
- **Skill**: Categorized technical stack and proficiency indicators.
- **Resume**: Version-tracked CV document downloads.
- **Visitor & AnalyticsEvent**: Privacy-first telemetry and interaction logs.
- **ContactMessage**: Inbound messaging from portfolio hire forms.
- **Notification**: Real-time push and dashboard alert feed.
- **SiteSettings**: Dynamic site-wide availability toggles and announcements.
